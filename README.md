# AJ Tech Maestros Website

Website for **ABE & JACK TECH MAESTROS LTD**, trading publicly as **AJ Tech Maestros**.

## Brand

- Public brand: AJ Tech Maestros
- Monogram: AJTM
- Tagline: Design. Engineer. Create.
- Legal entity: ABE & JACK TECH MAESTROS LTD

## Stack

- Astro
- Tailwind CSS (tokens and blueprint component classes live in `src/styles/global.css`)
- Barlow / Barlow Condensed via Google Fonts
- WhatsApp-first contact form, plus a Netlify Forms-compatible quote form at `/request-quote/`
- GitHub Actions build validation

## Migration

This repository is the new home for the website previously developed under the **Abe3D** brand. The migration preserves the useful Abe3D foundation while broadening the company positioning into product design, CAD, digital fabrication, rapid prototyping, engineering support, technical training and future technology products.

The old Abe3D repository remains untouched as an archive/reference.

### Migrated/reworked

- Responsive site shell, navigation and footer
- Core 3D printing, CAD, prototyping, replacement-part and small-batch services
- Technical-training material previously structured as Abe3D Academy
- Affordable Prostheses Project and assistive-technology content previously structured as Abe3D Impact
- Contact routes and WhatsApp integration
- Full quote/inquiry form with file upload and Netlify form detection
- Thank-you page
- Products and projects structure
- AJ Tech Maestros metadata, styling and temporary brand mark
