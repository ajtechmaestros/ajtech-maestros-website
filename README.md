# AJ Tech Maestros Website

Website for **ABE & JACK TECH MAESTROS LTD**, trading publicly as **AJ Tech Maestros**.

## Brand

- Public brand: AJ Tech Maestros
- Monogram: AJTM
- Tagline: Design. Engineer. Create.
- Legal entity: ABE & JACK TECH MAESTROS LTD

## Stack

- Astro
- Tailwind CSS

This repository is the new home for the website previously developed under the Abe3D brand. The rebrand broadens the focus from 3D printing into product design, CAD, digital fabrication, rapid prototyping, engineering and future technology products.
